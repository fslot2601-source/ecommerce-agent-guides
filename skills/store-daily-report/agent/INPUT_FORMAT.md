# 第一版支持的输入

同一目录中提供 `.xlsx` 或 CSV（UTF-8 / GB18030）。按表头识别，不依赖文件名；Excel 可含多个表，表头需在前20行。暂不支持 xls、加密工作簿、跨店合并、其他平台自动字段映射。Excel 公式需有可读取的缓存值，否则按缺失处理。

| 报表 | 识别必需表头 | 其他计算字段 |
| --- | --- | --- |
| 交易概况 | 时间、店铺访客数、成交金额、成交单量 | 成交商品件数、成交客户数可选；访客值可缺失 |
| 商品明细 | 时间、商品ID、商品名称、成交金额 | 成交单量、成交商品件数可选 |
| 全站营销 | 日期、ID、投放类型、花费、全站交易额 | 商品计划名称必需；全站订单行可选 |
| 快车 | 日期、跟单SKU ID、计划ID、花费、总订单金额 | 跟单SKU名称或推广计划必需；总订单行可选 |

日期支持 YYYY-MM-DD、YYYYMMDD、YYYY/MM/DD、YYYY.MM.DD 和 Excel 日期单元格。报表“合计/总计/汇总”行跳过；商品明细时间为空且商品ID为合计/总计的行也跳过。其他不合法日期报错。

金额必须是非负有限数字；计数为非负整数。千位逗号可读取，金额不要带货币符号；原始百分比列不直接相加。交易转化率由成交客户数÷店铺访客数重算，缺其中之一时不生成。

商品与计划编号保留为文本；Excel 超过15位的数字编号会报错，避免丢失精度后错误匹配。快车键为日期+SKU+计划，全站键为日期+投放类型+ID；每张日表的唯一性必须成立。整文件内容重复自动跳过并列入文件清单，其余重复键拒绝计算。

推广“无记录”不代表零投放；确认没有投放时可提供一条真实零花费/零交易额记录，或让日报保持缺失说明。PDF是可选输出，不需要数据库或在线服务。
